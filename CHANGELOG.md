# Changelog

## 0.1.0

First release.

- Browse repository issues and your own issues in the sidebar.
- Choose between a one-line list and detailed cards.
- Sign in with the GitHub CLI or with VS Code.
- Drag issues from the list into editors, terminals and AI agent inputs.
- Read issues in full, with comments, labels, assignees and milestones.
- Copy issues as Markdown, or copy their URLs.
- Filter by state and search with GitHub search syntax.
